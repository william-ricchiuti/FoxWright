Set up Foxwright

One command, then you're ready.

Foxwright lets an AI agent you run on this computer, such as Claude Code, read and operate Firefox tabs, with your permission for each site. To talk to the agent, Firefox needs a small helper program on this computer.

1 · Install the helper

Open a terminal and run:

npx foxwright-firefox setup --claude-code

Needs Node.js 20 or newer (node --version shows yours).

Using Claude Desktop? Use --claude-desktop instead (or both). For any other MCP client, leave the flag off: setup prints the settings to paste into it.

2 · Connection

Looking for the helper…

This page notices the helper by itself within a few seconds. No need to restart Firefox.

3 · Ask your AI to use Foxwright

Restart your AI client so it picks up the new tool, then ask it something like:

“Use Foxwright to open my GitHub notifications and summarize them.”

How you stay in control

  • You approve each site. The first time the agent wants a site, Foxwright asks you in its own small window: Deny, Allow this session, or Always allow. Change your answers later in the toolbar popup.
  • The agent has its own tabs. It works only in the orange “Foxwright” tab group. Drag a tab into the group to share it.
  • Stop it at any time. Press Stop on the page while the agent works, Pause in the toolbar popup, or Alt+Shift+K. Nothing happens until you resume.
  • See what it did. The activity log lists the agent's actions and your answers.
