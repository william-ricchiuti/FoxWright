Set up Foxwright

Three steps, about five minutes.

Foxwright lets an AI app on this computer, such as Claude Desktop, Claude Code, Cursor or Codex, read and use Firefox tabs. It asks you before it touches each website. Firefox needs a small free helper program to talk to your AI app.

1 · Install the helper

Which AI app will use Firefox?

Open a terminal and run:

npx foxwright-firefox setup --claude-code

The terminal says “command not found”, “not recognized” or “needs Node.js 20”

The helper runs on Node.js 20 or newer, which isn't installed yet (or is too old). Then run the command above again.

In PowerShell, “running scripts is disabled on this system” means PowerShell blocked npx. Type npx.cmd instead of npx, or use Command Prompt.

2 · Connection

Looking for the helper…

This page notices the helper by itself within a few seconds. No need to restart Firefox.

3 · Ask your AI to use Foxwright

Restart your AI app so it loads Foxwright, then ask it:

“Use Foxwright to open https://example.com, tell me the main heading, and close the tab when you're done.”

A small Foxwright window then asks whether the agent may use example.com. Choose Allow this session. Tick Read only first if you only want it to look.

How you stay in control

  • You approve each site. The first time the agent wants a site, Foxwright asks you in its own small window. Allow this session lasts until you quit Firefox, Allow for 1 hour ends after an hour, Always allow keeps it. Read only lets the agent look but not click or type. Change your answers later in the toolbar popup.
  • The agent has its own tabs. It works only in the orange “Foxwright” tab group. Drag a tab into the group to share it.
  • Stop it at any time. Press Stop on the page while the agent works, Pause in the toolbar popup, or Alt+Shift+K. Nothing happens until you resume.
  • See what it did. The activity log lists the agent's actions and your answers.
